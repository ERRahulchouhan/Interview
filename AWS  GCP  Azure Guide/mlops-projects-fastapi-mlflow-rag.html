Two MLOps Projects on AWS, GCP and Azure

Project 1: FastAPI + ML model + MLflow on Kubernetes. Project 2: FastAPI RAG + Redis + PostgreSQL/pgvector on Kubernetes. Each cloud: CLI and Terraform.

Read first: untested starting points. Replace <placeholders>. Kubernetes versions, module versions and CLI flags change, so check current docs. Clusters, NAT gateways and load balancers cost money: delete everything when done (section 5). To keep this runnable, PostgreSQL and Redis run inside the cluster (learning setup); section 4 shows how to swap to managed services. Auth to the artifact bucket uses IAM-based pod identity on AWS and GCP; Azure uses a storage key in a Secret for brevity (use Workload Identity in production). The LLM is any OpenAI-compatible API you provide (Bedrock, Vertex and Azure OpenAI can be used through compatible gateways or by changing the client code).

2. Project 1: FastAPI + ML model + MLflow on Kubernetes

Flow: MLflow server stores runs in PostgreSQL and model files in the bucket. A training Job logs a scikit-learn model and gives it the alias champion. The FastAPI service loads models:/iris@champion and serves /predict.

ml-api/app.py

import os
import mlflow, mlflow.pyfunc
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

mlflow.set_tracking_uri(os.environ["MLFLOW_TRACKING_URI"])
app = FastAPI()
_model = None

class Req(BaseModel):
    features: list[list[float]]    # e.g. [[5.1, 3.5, 1.4, 0.2]]

def get_model():
    global _model
    if _model is None:
        _model = mlflow.pyfunc.load_model("models:/iris@champion")   # loaded lazily
    return _model

@app.get("/health")
def health():
    return {"status": "ok"}

@app.post("/predict")
def predict(r: Req):
    try:
        return {"prediction": get_model().predict(r.features).tolist()}
    except Exception as ex:
        raise HTTPException(503, f"model not ready: {ex}")

ml-api/train.py

import mlflow, mlflow.sklearn
from sklearn.datasets import load_iris
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

mlflow.set_experiment("iris")
X, y = load_iris(return_X_y=True)
Xtr, Xte, ytr, yte = train_test_split(X, y, random_state=0)
with mlflow.start_run():
    m = RandomForestClassifier(n_estimators=100).fit(Xtr, ytr)
    mlflow.log_metric("accuracy", m.score(Xte, yte))
    info = mlflow.sklearn.log_model(m, artifact_path="model")
mv = mlflow.register_model(info.model_uri, "iris")
mlflow.MlflowClient().set_registered_model_alias("iris", "champion", mv.version)
print("registered iris version", mv.version)

3. Project 2: FastAPI RAG + Redis + PostgreSQL/pgvector on Kubernetes

Flow: /ingest embeds text (sentence-transformers, 384 dimensions) and stores it in pgvector. /ask checks the Redis cache, otherwise finds the nearest chunks in pgvector, asks the LLM to answer from them, and caches the reply.

rag-api/app.py

import os, hashlib
from contextlib import asynccontextmanager
import psycopg, redis
from fastapi import FastAPI
from openai import OpenAI
from pgvector.psycopg import register_vector
from pydantic import BaseModel
from sentence_transformers import SentenceTransformer

URL = os.environ["DATABASE_URL"]
emb = SentenceTransformer("all-MiniLM-L6-v2")
cache = redis.from_url(os.environ["REDIS_URL"])
llm = OpenAI(base_url=os.getenv("LLM_BASE_URL") or None, api_key=os.environ["LLM_API_KEY"])

@asynccontextmanager
async def lifespan(app):
    with psycopg.connect(URL, autocommit=True) as c:
        c.execute("CREATE EXTENSION IF NOT EXISTS vector")
        c.execute("CREATE TABLE IF NOT EXISTS docs (id serial PRIMARY KEY, content text, embedding vector(384))")
        c.execute("CREATE INDEX IF NOT EXISTS docs_hnsw ON docs USING hnsw (embedding vector_cosine_ops)")
    yield

app = FastAPI(lifespan=lifespan)

def db():
    c = psycopg.connect(URL, autocommit=True)
    register_vector(c)
    return c

class Ingest(BaseModel):
    texts: list[str]

class Ask(BaseModel):
    question: str

@app.get("/health")
def health():
    return {"status": "ok"}

@app.post("/ingest")
def ingest(b: Ingest):
    vecs = emb.encode(b.texts)
    with db() as c:
        for t, v in zip(b.texts, vecs):
            c.execute("INSERT INTO docs (content, embedding) VALUES (%s, %s)", (t, v))
    return {"ingested": len(b.texts)}

@app.post("/ask")
def ask(b: Ask):
    key = "ans:" + hashlib.sha256(b.question.encode()).hexdigest()
    hit = cache.get(key)
    if hit:
        return {"answer": hit.decode(), "cached": True}
    with db() as c:
        rows = c.execute("SELECT content FROM docs ORDER BY embedding <=> %s LIMIT 4", (emb.encode(b.question),)).fetchall()
    ctx = "\n---\n".join(r[0] for r in rows)
    out = llm.chat.completions.create(model=os.getenv("LLM_MODEL", "gpt-4o-mini"), messages=[
        {"role": "system", "content": "Answer only from the context. If unknown, say you don't know."},
        {"role": "user", "content": f"Context:\n{ctx}\n\nQuestion: {b.question}"}])
    ans = out.choices[0].message.content
    cache.set(key, ans, ex=3600)
    return {"answer": ans, "cached": False}

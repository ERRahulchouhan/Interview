EDA Steps: Methods and Production Use

Every step from your EDA file, with the method names and whether each one is used in production.

✔ Used in production▲ Use with care✖ Notebook or exploration only
Golden rule: any step that learns from data (imputer, scaler, encoder, selector, PCA) is fit on train data only, placed inside a Pipeline, and saved with joblib. The same object then transforms new data when serving.

How these steps look in production

from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder, PowerTransformer
from sklearn.decomposition import PCA
import joblib

num_pipe = Pipeline([
    ("impute", SimpleImputer(strategy="median", add_indicator=True)),  # step 4
    ("transform", PowerTransformer()),                                 # step 12
    ("scale", StandardScaler()),                                       # step 11
])
cat_pipe = Pipeline([
    ("impute", SimpleImputer(strategy="most_frequent")),               # step 4
    ("encode", OneHotEncoder(handle_unknown="ignore")),                # step 10
])
pre = ColumnTransformer([("num", num_pipe, num_cols),
                         ("cat", cat_pipe, cat_cols)])

model = Pipeline([("pre", pre),
                  ("pca", PCA(n_components=0.95)),                     # step 14
                  ("clf", clf)])                                       # step 15

model.fit(X_train, y_train)          # fit on train only
joblib.dump(model, "model.joblib")   # same object used for serving

Steps 3, 6, 7 and the plots in 8 and 9 are mostly notebook work. Steps 4, 5, 10 to 15 become Pipeline code. Step 5 also gets automated validation, and the stats from steps 6 and 7 are saved as a baseline for drift monitoring.

Tree models (Random Forest, XGBoost, LightGBM) need no scaling. XGBoost, LightGBM, CatBoost and HistGradientBoosting handle NaN natively.

# Master Prompt: Complete Machine Learning Algorithms – Beginner to Production Level

Act as a Senior Machine Learning Engineer, ML Architect, Data Scientist, and MLOps Engineer with 10+ years of production experience.

Build a complete, industry-standard Machine Learning learning repository using Python, NumPy, Pandas, Scikit-learn, XGBoost, LightGBM, CatBoost, and other relevant ML libraries.

The goal is to learn every major ML algorithm from beginner to advanced level and understand how to implement, evaluate, optimize, deploy, monitor, and maintain each algorithm in real-world production systems.

## 2. Mandatory notebook structure for EVERY algorithm

Every individual algorithm folder must contain:

```text
Algorithm_Name/
│
├── Algorithm_Name.ipynb
├── README.md
├── requirements.txt
├── config.yaml
├── train.py
├── predict.py
├── evaluate.py
├── preprocessing.py
├── model.py
├── test_model.py
├── Dockerfile
│
├── data/
│   ├── raw/
│   ├── processed/
│   └── external/
│
├── models/
├── logs/
├── reports/
│
└── artifacts/
```

Do not put all algorithms into one notebook.

Each algorithm must have its own complete notebook with separate executable cells.

## 3. Mandatory cell-wise notebook format

Create notebooks with the following cells in the same sequence.

**Cell 1: Algorithm introduction**
- What is the algorithm?
- Why do we need it?
- When should we use it?
- Real-world examples.
- Business use cases.
- Industry applications.

**Cell 2: Mathematical intuition**
- Mathematical formula.
- Explanation of every variable.
- Derivation where applicable.
- Assumptions.
- Objective function.
- Cost/loss function.

**Cell 3: Working mechanism**
- Step-by-step algorithm execution.
- Internal working.
- Simple numerical example.
- Manual calculation.
- Visual explanation.

**Cell 4: Algorithm from scratch**
- Implement using pure Python and NumPy.
- Do not use sklearn for the algorithm implementation.
- Explain each line.
- Add a manual dry run.
- Explain time and space complexity.

**Cell 5: Dataset**
- Use an appropriate real-world or publicly available dataset.
- Explain every feature.
- Explain target variable.
- Show dataset shape and sample records.
- Explain data collection and business context.
- Provide a synthetic fallback so the notebook runs offline.

**Cell 6: Exploratory Data Analysis**
- Shape and data types.
- Missing values.
- Duplicate records.
- Statistical summary.
- Distribution analysis.
- Correlation.
- Outlier detection.
- Data visualization.
- Target distribution.

**Cell 7: Data preprocessing**
- Missing value imputation.
- Categorical encoding.
- Feature scaling.
- Outlier handling.
- Feature transformation.
- Train/validation/test split.
- Prevent data leakage.
- Use sklearn Pipeline and ColumnTransformer.

**Cell 8: Baseline model**
- Build the simplest baseline.
- Train the model.
- Make predictions.
- Explain model parameters.
- Understand model output.

**Cell 9: Detailed training**
- Fit model.
- Explain internal training process.
- Explain hyperparameters.
- Show training results.
- Compare training and testing performance.

**Cell 10: Evaluation**
Include relevant metrics for the algorithm.

Regression:
- MAE
- MSE
- RMSE
- R2
- Adjusted R2
- MAPE and limitations
- Residual analysis

Classification:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
- ROC-AUC
- PR-AUC
- Log loss
- Specificity
- Sensitivity
- Balanced accuracy
- Matthews correlation coefficient

Clustering:
- Silhouette score
- Davies-Bouldin index
- Calinski-Harabasz index
- Cluster visualization
- Business interpretation

**Cell 11: Overfitting and underfitting**
- Detect overfitting.
- Detect underfitting.
- Bias-variance tradeoff.
- Learning curves.
- Validation curves.
- Regularization.
- Practical solutions.

**Cell 12: Hyperparameter optimization**
- GridSearchCV.
- RandomizedSearchCV.
- Optuna.
- Bayesian optimization.
- Cross-validation.
- Explain each important parameter.
- Compare default vs optimized model.

**Cell 13: Feature importance and explainability**
- Coefficients or feature importance.
- Permutation importance.
- SHAP.
- LIME where applicable.
- Explain individual predictions.
- Identify bias and fairness issues.

**Cell 14: Advanced techniques**
- Algorithm-specific optimizations.
- Class imbalance handling.
- Feature selection.
- Model calibration where applicable.
- Ensemble comparison.
- Computational optimization.

**Cell 15: Production-level implementation**
- Modular Python code.
- Separate training and prediction scripts.
- Configuration-driven training.
- Logging.
- Exception handling.
- Input validation.
- Reproducibility.
- Model serialization.
- Model versioning.
- Unit tests.

**Cell 16: Model deployment**
- FastAPI REST endpoint.
- Request/response schemas.
- Batch inference.
- Real-time inference.
- Docker containerization.
- Health endpoint.
- Readiness endpoint.
- Model loading strategy.

**Cell 17: MLOps**
- MLflow experiment tracking.
- Model registry.
- Data versioning.
- Model monitoring.
- Data drift detection.
- Concept drift detection.
- Retraining strategy.
- CI/CD.
- Rollback strategy.

**Cell 18: Performance optimization**
- CPU and memory usage.
- Inference latency.
- Throughput.
- Batch prediction.
- Parallel processing.
- Model size.
- Scalability.

**Cell 19: Production case study**
Create a realistic industry use case for this algorithm.

Include:
- Business problem.
- Data architecture.
- ML architecture.
- Training pipeline.
- Inference pipeline.
- Monitoring.
- Failure scenarios.
- Business metrics.
- Production trade-offs.

**Cell 20: Interview preparation**
- 20 beginner questions.
- 20 intermediate questions.
- 20 advanced questions.
- 10 mathematical questions.
- 10 production scenario questions.
- Answers with practical examples.

**Cell 21: Exercises**
- Beginner exercises.
- Intermediate exercises.
- Advanced exercises.
- Coding challenges.
- Production implementation challenges.
- Solutions in a separate notebook or solution section.

2. Reproducible experiments.
3. Fixed random seeds where appropriate.
4. Train/validation/test separation.
5. Configuration-driven pipelines.
6. Structured logging.
7. Type hints and docstrings.
8. Input schema validation.
9. Unit and integration tests.
10. Model artifact versioning.
11. Monitoring and alerting.
12. Secure API design.
13. Docker deployment.
14. Kubernetes deployment.
15. CI/CD pipeline.
16. Rollback and retraining strategy.

Do not claim a model is production-ready merely because its notebook executes successfully.
